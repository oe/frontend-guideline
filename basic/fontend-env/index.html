前端开发环境的安装配置

目标很明确：终端能找到正确的 Node 和包管理器，编辑器打开正确的项目目录，同一套命令能在本机和 CI 运行。 先完成这几件事，再装终端主题。

安装编辑器

Section titled “安装编辑器”

默认安装 VS Code，再按工具清单添加项目真正需要的扩展。编辑本站安装 Astro 扩展，Vue 3 项目安装 Vue (Official)，不要看到「前端扩展包」就整套装进去。

安装 Node.js

Section titled “安装 Node.js”

新项目选当前受支持的 LTS，不要因为下载页出现了更新的 Current 就立刻换。版本时间表见 Node.js Releases。

接手项目按下面顺序看：README → .nvmrc / .node-version → package.json 的 engines。fnm 的 --use-on-cd 能根据版本文件切换；本书仓库有 .nvmrc，安装对应版本后再启动项目。

启动与排查

Section titled “启动与排查”

按这个顺序查，通常比重装软件快：

现象先检查
node / pnpm 找不到重新打开终端；确认 fnm 初始化行生效，再看 command -v node 和 command -v pnpm
Node 版本不对pwd 确认目录，查看版本文件，运行 fnm use 与 node --version
Missing script: dev看 package.json 的 scripts；可能应运行 start，也可能打开了错误目录
锁文件不匹配确认包管理器版本、分支和 package.json 是否同步；别先删锁文件
原生模块、平台相关报错确认 arm64/x64 和 Windows/WSL 是否混用；按正确环境重新安装依赖
端口被占用看占用进程，停止旧开发服务，或按工具提示选择另一个端口

终端出现本地地址后再打开浏览器；生产上线前执行构建和预览。下一步是创建第一个项目。
