工欲善其事必先利其器(硬件篇)

开发笔记本，首推 MacBook；预算有限再选 Windows。 日常前端开发优先买内存、屏幕、续航和输入体验，别为了独显和跑分背一台又重又吵的游戏本。

更新于 2026-10-19。个人选型建议，依据公开规格与开发负载分析编写，非全机型实测。价格、库存与可选配置以购买时为准。

电脑

Section titled “电脑”

选购速查

Section titled “选购速查”
你的用途本书推荐建议配置
学习前端、预算刚够 MacBookMacBook Air M516GB / 512GB
每天写业务代码，准备作为主力机MacBook Air M524GB / 1TB
大型仓库、多容器、模拟器、长时间构建MacBook Pro 14 英寸，M5 Pro48GB / 1TB
不需要移动，已有显示器和键鼠Mac mini M624GB / 512GB，镜像多则 1TB
预算够不到合适的 MacBookWindows 集显轻薄本32GB / 1TB

不确定就从第二行开始选。 预算差一点先保 24GB 内存，SSD 可退到 512GB；轻量学习的 16GB 配置也能起步。Pro 主要买持续负载能力与内存余量，普通业务开发不用追 Max；Windows 则把屏幕、内存与 SSD 买够，不给入门独显交税。

对应的在售芯片、内存与存储组合已按 M5 Air、M5 Pro / Max MacBook Pro、M6 / M5 Pro Mac mini 的规格核对。Mac 的内存档位随芯片变化，例如 M5 Pro 选 24GB、48GB 等配置，别拿 Windows 的「32GB 标配」直接套在所有 Mac 上。

Mac

Section titled “Mac”

大多数前端开发者，先看 Air，再决定是否需要 Pro。

  • 13 英寸 Air：经常背着走，回家或到公司接外屏，优先选它。
  • 15 英寸 Air：经常只用笔记本自带屏幕写代码，优先选它；更大的可视面积比多几个 GPU 核心实用。
  • 14 英寸 Pro：经常持续跑构建、多个服务和模拟器，或者确实想要更好的屏幕、接口与持续性能，再上 Pro。M5 Pro 对这类工作更有意义，Max 的预算主要花在更强 GPU 等能力上。
  • 16 英寸 Pro：长时间只用内屏、能接受重量再买。日常通勤加外屏，14 英寸更好带。

M5 Air 是无风扇设计，日常安静是优点；连续高负载不该按有主动散热的 Pro 来期待。M5 Air 已支持内屏同时搭配两台外接屏，「接两台外屏就必须买 Pro」已经过时；显示器数量和分辨率组合见上面的官方规格。

已有 16GB 或更大内存的 M2、M3、M4 MacBook，日常项目跑得顺就继续用。新购不推荐 8GB / 256GB 的低配旧机，也不推荐为了便宜买 Intel Mac；省下的钱容易变成内存压力、磁盘清理和系统支持的麻烦。同价位的上一代大内存机器与新一代小内存机器，本书更偏向前者。

Windows

Section titled “Windows”

预算有限时，优先 32GB 内存、1TB SSD、集成显卡的轻薄本。例如小新 Pro 14 酷睿 Ultra 5 336H 配置，官方已提供 32GB / 1TB / 集显组合；锐龙 AI 7 H 450 配置也有相近档位。它们是找配置的具体起点，买哪个取决于当时成交价，别只追同系列最贵的 CPU。

筛选商品时按这个顺序：

  1. 内存与存储：32GB / 1TB 优先于高一档 CPU 配 16GB / 512GB。板载内存买前就配够。
  2. 屏幕：看实际面板的色域、亮度和反光。预算内优先 100% sRGB、16:10 的高分辨率屏；同一系列也可能有低色域版本。
  3. 输入与续航：到店敲键盘、拖动触摸板，查轻负载续航实测；别拿厂商视频播放时长当开发续航。
  4. 接口与维修：确认 USB-C 能充电和输出视频、内存能否升级、售后网点是否方便。

不建议初学者把 Windows on Arm 当默认选项。x86-64 机器更省心；Arm 版的原生依赖、容器镜像和调试工具得逐项确认，Docker Desktop 的 Windows Arm 支持目前仍标为 Early Access。

平台/系统

Section titled “平台/系统”

苹果/macOS

Section titled “苹果/macOS”

首推 MacBook 的理由很具体：日常开发可直接使用 Unix 风格终端，屏幕、触摸板和续航的整体体验值得花钱，Safari / iPhone 调试也方便。配好 Homebrew、Node 版本管理、编辑器和浏览器就能开工，安装步骤见开发环境配置。

Apple silicon 机器优先安装 arm64 版本工具。旧项目要求 x86 原生模块或镜像时，单独处理兼容问题，别把整套环境都长期放在转译模式下跑。

微软/Windows

Section titled “微软/Windows”

新装开发环境用 Windows 11，推荐 Windows Terminal + WSL 2 + Ubuntu，编辑器装在 Windows，通过 WSL 扩展打开 Linux 内的项目。

项目放在 ~/projects/，在 WSL 内安装 Node、Git 和依赖；别在 /mnt/c/ 上用 Linux 工具反复扫描 node_modules，也别让 Windows 和 Linux 共用同一份依赖目录。微软的文件系统建议解释了原因。具体操作见环境配置。

Linux

Section titled “Linux”

不把折腾桌面 Linux 当作前端入门任务。想学 Linux 工具链，先用 WSL 或远程开发；确实要装桌面 Linux，新装优先 Ubuntu 26.04 LTS。安装前用 Live USB 实际试无线网络、休眠和外接屏，驱动不合适就换硬件方案，别把几天开发时间耗在修休眠上。

内存、硬盘和 AI：钱先花在哪里

Section titled “内存、硬盘和 AI：钱先花在哪里”
  • 内存先于 CPU 小幅升级。 浏览器、编辑器、TypeScript 服务、容器都会占内存。16GB 是新购的起步档，Mac 主力机推荐 24GB 起，Windows 主力机推荐 32GB；多容器和模拟器再往上加。
  • 512GB 能用，1TB 更省事。 node_modules、pnpm store、Docker 镜像、模拟器会持续占空间。已有外置 SSD 可以放归档、素材和备份，常用项目与开发缓存仍优先放内置盘。
  • 用云端 AI 编程，不需要专门买独显或追 NPU TOPS。 先把内存、网络和工具预算安排好。确实要本地运行大模型，再按具体模型的显存/内存需求单独选型，不要指望一台入门轻薄本包办所有 AI 工作。
  • 备份从第一天开始。 Git 远程仓库备份代码历史；本机资料用 Time Machine 或独立备份盘。没有提交和推送的代码，不会因为装了 Git 自动得到备份。

显示器

Section titled “显示器”

写代码和看文档，先买一块好的主屏，再考虑堆第二、第三块屏。

选择推荐用途本书的判断
27 英寸 4K IPS默认外接主屏清晰度、桌面占用和价格比较均衡；60Hz 能用，预算够优先 120Hz
27 英寸 5K对文字清晰度要求高的 Mac 用户200% 缩放下可获得相当于 2560×1440 的逻辑工作区，文字更细腻，价格也更高
32 英寸 4K喜欢大屏、桌面够深可视面积大，但像素密度低于 27 英寸 4K，建议现场看文字大小与观看距离
超宽屏明确需要横向多窗口先看垂直像素；3440×1440 不会因为叫「带鱼屏」就比 4K 更细腻

具体参考：Dell U2725QE 是 27 英寸 4K / 120Hz，并提供最高 140W 的雷雳供电；BenQ PD2730S 是 27 英寸 5K / 60Hz、雷雳 4 / 90W，偏向文字与设计工作。它们是两种取舍的例子，无需为了写业务代码强上专业设计屏。

优先选带高度调节、USB-C 视频和供电的型号，一根线回到工位更舒服。买前确认三个实际问题：

  1. 能否在你要的分辨率与刷新率下输出，别只看包装上的「支持 4K」。
  2. 显示器供电是否够笔记本使用；高负载下供电不够时可能还要接原装充电器。
  3. 双屏扩展坞是否明确支持 Mac 的两台独立扩展屏。普通 MST 双 HDMI 扩展坞在 macOS 下可能只能镜像，厂商说明写得很清楚；不确定就先用两路直连。

OLED 的黑位和观感很好，但本书不把它作为长时间显示 IDE、浏览器固定界面的默认首选。更在意文字观感、反光与长期静态显示的顾虑时，先看 IPS；想买 OLED 就拿实际编辑器界面现场看一遍。

键鼠

Section titled “键鼠”

MacBook 先把自带键盘和触摸板用熟，外接屏后再配独立键鼠。外接键盘推荐 75% 或 TKL 配列，保留方向键和常用快捷键；想试机械键盘可从 Keychron 的 Mac 布局机型入手。办公室先选安静的轴体，别让同事替你欣赏敲击声。

鼠标可以先看 Logitech MX Master 4，重视滚轮与多按键时很实用；它体积和重量不小，小手或经常出差的人先试握。别为了所谓程序员身份买一套很贵、自己却用不顺的外设。

电脑桌

Section titled “电脑桌”

桌面建议从 120×70cm 起，放 27 英寸外屏、笔记本和键鼠更宽裕；桌子太浅，屏幕和手臂都没地方放。稳定、合适的高度和理线空间，比「电竞桌」标签有用。

旧稿里我用的是宜家 1.25m × 0.75m 的餐桌，当时约 350 元。这个例子保留的理由很简单：普通餐桌也能成为好工位，没必要为「程序员专用」买单。要买升降桌，重点试最低高度是否适合坐姿、升高后晃不晃、显示器支架能不能装。

椅子

Section titled “椅子”

椅子比 RGB 灯条值得花钱。买前坐上去试座深、腰靠和扶手：脚能踏实落地，手臂能自然放下，椅背能支撑自己；不合身就换型号，别指望贵就自动舒服。久坐仍要起身活动。

其他

Section titled “其他”

外设购买顺序建议是：主屏 → 独立键鼠与支架 → 备份盘 → 真正需要的扩展坞。屏幕灯、RGB、昂贵桌搭最后再说。先把每天工作都在受的罪解决掉，比凑一张好看的桌面照片划算。
