开发设备应满足实际项目需求。先确认需要运行的软件、团队环境和预算，再比较性能、续航、接口、维修与售后；品牌和操作系统本身不能保证稳定性、安全性或性价比。

## 平台/系统

macOS、Windows 和常见桌面 Linux 发行版都能进行前端开发。浏览器、Node.js、编辑器以及项目依赖的支持范围，通常比操作系统偏好更影响选择。

### 苹果/macOS

macOS 与 Apple 硬件集成，适合需要同时使用 Safari、Xcode 或 Apple 平台开发工具的场景。价格、内存和存储配置的升级空间因机型而异，购买前需要确认。

- Apple silicon 使用 ARM 架构，应检查原生依赖、Docker 镜像和虚拟化工具是否支持；不能假设所有 x86 软件都能无差别运行。
- 外设可能需要额外软件或驱动，兼容性应查厂商说明。
- 系统升级通常不单独收费，但受机型支持范围限制；升级前应备份并核对关键软件兼容性。
- macOS 也可能受到恶意软件、钓鱼和不安全扩展影响，需要正常更新系统并管理软件权限。

参考 [Mac 机型](https://www.apple.com/mac/)与 [Mac 备份指南](https://support.apple.com/mac-backup)。

### 微软/Windows

Windows 设备型号与价格范围较广，也适合需要 Windows 专用软件的工作。可以使用原生工具，或通过 [WSL](https://learn.microsoft.com/zh-cn/windows/wsl/about) 运行 Linux 开发环境。

- 硬件性能、触摸板体验与驱动质量取决于具体机型，不能一概而论。
- Windows 11 的免费升级有硬件、许可证和系统状态等条件，并非所有系统升级都需要付费，也不都需要重装。
- Windows 10 22H2 Home/Pro 的常规支持已于 2025 年 10 月 14 日结束；使用旧设备时应确认受支持系统或扩展安全更新方案。
- 使用 WSL 时，注意 Windows 与 Linux 路径、大小写和文件权限的差异；开发文件的放置位置也会影响 I/O 性能。

参考 [Windows 11 升级说明](https://www.microsoft.com/windows/get-windows-11)与 [Windows 10 生命周期](https://learn.microsoft.com/en-us/lifecycle/products/windows-10-home-and-pro)。

### Linux

Linux 是操作系统内核，日常所说的桌面 Linux 通常指 Ubuntu、Fedora 等发行版。它适合希望使用 Linux 工具链或贴近服务端环境的开发者。

购买前核对无线网卡、显卡、休眠、外接屏等硬件支持，以及工作所需商业软件是否可用。不同发行版的安装与维护方式不同，初次尝试可以先使用虚拟机或已有设备体验。

参考 [Ubuntu Desktop](https://ubuntu.com/desktop)与 [Fedora Workstation](https://fedoraproject.org/workstation/)。

## 电脑

普通前端开发通常更依赖 CPU、内存和存储速度，不一定需要独立显卡。WebGL、三维渲染、视频处理等任务需另行评估 GPU。

- **内存**：轻量学习可以使用现有设备；新购用于日常开发时可将 16GB 作为参考起点，同时运行大型 IDE、多个容器或模拟器时考虑 32GB 或更多。
- **存储**：建议使用 SSD，容量根据仓库、依赖缓存、镜像和其他工作资料预留；512GB 是常见参考配置，不是工具的统一最低要求。
- **便携与扩展**：移动办公关注重量、续航和充电器，固定办公关注散热、外接屏数量与接口。
- **维护**：确认内存和存储能否升级、保修范围、维修成本，以及二手设备的电池与系统支持情况。

### Mac

MacBook Air/Pro、Mac mini、iMac、Mac Studio 等系列面向不同需求，型号会持续更新。入门前端项目通常不需要最高配置，应根据预算与实际负载选择，不能由售价或“Pro”名称直接推断是否合适。

### Windows

比较具体型号的 CPU、内存、屏幕、散热、续航和售后，不根据厂商所属行业判断质量。尽量从系统商店或软件项目的官网获取安装程序，并核对发布者；同样的原则也适用于 macOS 和 Linux。

## 键鼠

根据手型、键位、连接方式与使用姿势选择键盘、鼠标或触摸板。先确认系统支持、蓝牙或接收器兼容性，再比较附加功能。长时间工作应定期休息，昂贵的外设不能替代合适的使用习惯。

## 显示器

分辨率、屏幕尺寸、缩放比例与观看距离共同影响文字的大小和清晰度。HiDPI 指高像素密度下的显示与缩放方式，并不是某一尺寸或分辨率的统一产品标准。

- 3840×2160 通常称为 4K UHD；5120×2880 是常见的 16:9 5K 分辨率。
- 5120×2160 常见于超宽屏，通常称为 5K2K，不能与 5120×2880 的显示面积和像素密度混为一谈。
- 优先实际查看文字清晰度、可用缩放比例、亮度、反光、刷新率与调节范围，再按预算选择。
- USB-C 只描述接口形态，不自动保证视频输出、数据带宽和 USB Power Delivery 供电。电脑、显示器与线缆需分别支持所需能力，并核对供电功率。

## 电脑桌

桌面应有足够空间放置屏幕和输入设备，高度与支撑结构适合自己的工作姿势。比较稳定性、承重、材料检测说明与保修，不能仅凭品牌或售价判断环保与安全。

## 椅子

关注座面高度、坐深、腰背支撑与可调范围，尽量试坐。合适的姿势和规律活动比单一价格门槛更有参考价值。

## 其他

根据工作环境决定是否需要屏幕灯、网络设备、扩展坞或外置存储。购买扩展坞前确认显示器数量、分辨率、刷新率、协议和充电需求是否能同时满足。
